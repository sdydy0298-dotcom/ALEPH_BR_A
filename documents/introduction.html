2023년, 낯설었던 첫 현장

첫 직장에서 백엔드 개발과 서버 배포를 함께 맡았습니다. Java로 기능을 만드는 방법은 배웠지만 실제 서버에 오류가 발생했을 때 무엇을 먼저 확인해야 할지는 익숙하지 않았습니다. 사수나 충분한 인수인계가 없는 상황에서 설정을 바꾸는 일도 조심스러웠습니다. 그래서 로그와 설정을 차례로 확인하며 문제가 발생한 범위를 좁혔습니다. 퇴근 후에도 부족한 내용을 공부하며 실무에 적용했습니다.

익숙한 일을 내려놓다

백엔드 업무 중 Windows 엔진 기술을 조사하며 파일과 시스템 동작을 직접 관찰하고 제어하는 기술에 호기심이 생겼습니다. C/C++는 낯설었지만 회사에 직무 전환을 요청했고, 이후 보안 솔루션과 DLP 개발에 참여했습니다. 동료와 기능·성능 문제를 나누어 분석하면서 다른 사람의 의견을 듣고 근거를 맞추는 일이 중요하다는 것을 배웠습니다.

로그 속에서 찾은 답

USB 저장 동작이 제대로 감지되지 않을 때 기존 코드를 무작정 수정하지 않고 실제 동작을 재현하고 앞뒤 로그를 비교했습니다. 정상적으로 감지되는 조건과 놓치는 조건을 구분해 반복 시험했고, 필요한 동작을 감지하는 결과를 확인했습니다. 전체 성능 개선은 동료와 함께한 결과였으며 혼자 이룬 성과라고 생각하지 않습니다.

2026년, 다시 배우는 오늘

대학 때 네트워크 수업은 어려워 관심을 접었고 정보처리기사 공부에서도 충분히 이해하지 못한 채 넘어갔습니다. 약 3년의 근무 경험 이후 더 다양한 기술을 경험하고 싶어 SKT-ALEPH 교육에 참여했습니다. 2026년 8월 13일 실습을 끝까지 수행한 일, 8월 21일 검색으로 해결책을 찾은 일, 9월 15일 옆 사람의 실습 문제를 함께 살펴본 일은 리추얼에 남긴 실제 기록입니다. 아직 진로를 한 분야로 정하지 않았습니다. 새로운 영역의 원리를 이해하고 직접 확인하며 여러 관점에서 문제를 풀 수 있는 엔지니어로 성장하고 싶습니다.

T09 서사와 T11 소설을 바탕으로 실제 경험만 추려 편집한 초안. 과제에서 요구하는 첫 문장과 마지막 문장 직접 작성·동료 피드백은 본인이 확인해야 합니다.
