## 누구를 어떻게 돕는가

DNS를 공부하거나 운영하는 사람이 공개 시험 결과의 응답시간과 초당 DNS 질의 수(QPS)를 비교하고, 숫자의 차이가 생긴 원인까지 확인한 것은 아니라는 점을 이해하도록 돕습니다.

## 짧은 재현·통과 확인 4줄

1. 공개 앱 URL을 시크릿 창에서 열거나 ZIP을 새 폴더에 풀고 `README.md`대로 `index.html`을 실행합니다. 첫 화면에서 T10 논문 제목과 앱 목적이 보이면 통과입니다.
2. `16 / 16` 부하를 선택하면 표가 2행으로 줄고, TTL 1초/3600초 평균 지연이 `0.2987ms` / `0.3080ms`로 표시되면 통과입니다.
3. `초당 질의 수(QPS)`를 누르면 지표가 바뀌고 `285,824` / `278,769` QPS가 나타나면 통과입니다. 단위 변환기에 `abc`를 넣으면 오류 메시지를 표시해야 합니다.
4. `현재 결과 보고서(.txt)`와 `요약 CSV 내려받기`를 누르면 해당 선택 결과 파일이 생성되면 통과입니다. BR-A의 대표작 카드에서 앱 링크가 열리는지도 확인합니다.

## AI와 내 판단 3줄 (내용 확인 후 제출)

- **AI에게 맡긴 일:** T10 연구 결과의 웹앱 구조 설계, 측정 요약값 시각화, 부하·지표 전환과 보고서 내보내기, 입력 검증 및 테스트 코드 구현을 맡겼습니다.
- **내가 직접 판단한 일:** 기존 T10 연구 및 BR-A 결과물은 유지하고 새 앱으로 작업하도록 정했습니다. 사이트를 시크릿 창에서 직접 확인했고, QPS·통계 용어가 어려워 이해하기 쉬운 설명으로 수정할 것을 요청했습니다.
- **AI 제안을 따르지 않은 일:** 이번 과제는 구현을 전반적으로 AI에 맡겨 별도로 거절한 기능 제안은 없습니다. 다만 논문의 어려운 표현을 화면에 그대로 둔 것은 사용자가 이해하기 어렵다고 판단해 쉬운 문장으로 수정하도록 요청했습니다.
