# BR-B 자동 점검 결과 · 2026-10-24 · v1.0.0

## 자동으로 직접 실행한 테스트

- `node tests/verify.mjs` — **20/20 PASS**: 실제 공개 원본에서 확인한 T10 집계 수치, 60개 세션 요약, 6개 그룹, TTL·QPS 차이, 연구 범위, 파일 및 보안 문자열 정적 점검.
- `node tests/interactions.mjs` — **16/16 PASS**: 실제 `data.js`·`app.js`를 별도 Node.js VM의 간이 DOM으로 로드하여 이벤트 처리, 필터, 지표 전환, 2행 CSV 다운로드, TXT 내용, 단위 변환, 오류/복귀, 초기화 검증.
- `python tests/smoke.py <ZIP 파일 경로>` — ZIP을 **새 임시 폴더**에 풀어 로컬 HTTP 서버로 HTML/CSS/JS 각 파일 200 응답 확인, 모든 핵심 파일 존재 및 ZIP 비암호화 확인.

## 자동 점검의 한계

Node.js 모의 DOM 테스트는 이벤트 처리·숫자 및 다운로드 생성 로직에 대한 테스트입니다. Chromium이 조직 정책으로 일반 URL 탐색을 차단하는 테스트 환경이어서 실제 브라우저의 화면 출력, 클릭과 모바일 레이아웃은 자동 실행 검증하지 못했습니다. 제출자는 일반 브라우저에서 README 2절의 세 사용자 행동과 모바일 화면을 확인해야 합니다.

## 수치 출처

T10 공개 DNSperf 원본 고정 커밋 300행 중 사전 명시된 조건을 만족하는 60행을 다시 읽어 집계했으며, 논문에 있는 6개 그룹의 수치와 대조 일치했습니다. 원문 자료는 재배포하지 않고, 본 연구가 작성한 6개 조건별 요약 수치만 `data.js`에 넣었습니다.
